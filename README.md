## 📂 Proyecto destacado

<div align="center">

### 🏢 Plataforma Web para la Gestión y Control de Tareas Operativas

Sistema web desarrollado para facilitar la planificación, asignación, seguimiento y control de tareas dentro de organizaciones.

[![Repositorio](https://img.shields.io/badge/VER_REPOSITORIO-007ACC?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Wygers/Gestor_Tareas_Proyecto_Titulo)

</div>

**🔹 Principales funcionalidades:**

- 🔐 Autenticación y control de acceso por roles.
- 👥 Administración de usuarios y organizaciones.
- 📋 Gestión, asignación y seguimiento de tareas.
- 📊 Control de estados, prioridades y porcentajes de avance.
- 🔗 Gestión de dependencias entre tareas.
- 📍 Ubicación geográfica asociada a tareas.
- 📁 Gestión y descarga de evidencias.
- 📧 Notificaciones por correo electrónico.
- 🔔 Notificaciones en tiempo real.
- 📝 Comentarios y auditoría de actividades.
- 📄 Generación de reportes PDF.
- 📊 Exportación de información a Excel.
- 📦 Descarga de evidencias comprimidas en ZIP.

**Tecnologías:** Node.js, Express.js, EJS, MySQL, JavaScript, Bootstrap y Socket.IO.
